# موقع قسم الذكاء الاصطناعي — كلية العلوم والتكنولوجيا · جامعة إقليم سبأ

مرجع الطلاب للمواد والمحاضرات والجدول الدراسي. موقع ثابت (HTML/CSS/JS) بلا أي أداة بناء،
يعمل على GitHub Pages كما هو، ويمكن فتحه محليًا بالنقر المزدوج على `index.html`.

## الهيكل

```
index.html          الرئيسية: المحاضرة القادمة (حية)، أسبوعك، المواد، المحاضرات المتاحة
courses.html        كل المواد مع بحث وتصفية
course.html?c=ID    صفحة مادة واحدة (تُبنى من البيانات)
schedule.html       الجدول التفاعلي: شبكة أسبوعية + قائمة + تفاصيل + تصدير للتقويم
data/data.js        ← مصدر البيانات الوحيد: المواد والمواعيد والمدرسون والمحاضرات
assets/css|js|img   التصميم والسلوك والصور (الخطوط مستضافة محليًا)
courses/<id-المادة>/ صفحات محاضرات كل مادة (+ ملفاتها). اسم المجلد = id المادة في data.js
courses/_template/  قالب محاضرة جديدة
chapter2.html       تحويل للروابط القديمة → courses/intro-computing/chapter-2.html
_archive/           النسخ الأصلية والمصادر القديمة (لا يُنشرها GitHub Pages لأن اسمها يبدأ بـ _)
```

## هوية صفحات المحاضرات
كل صفحة محاضرة تحمل `assets/css/lecture.css` (رموز التصميم + السمة الفاتحة/الداكنة) و`assets/js/lecture-shell.js`
(الشريط العلوي، التنقل السابق/التالي، التذييل — يقرأ ترتيب الفصول من `data/data.js` ويدعم العربية والإنجليزية).
محتوى الفصلين الأصلي وتفاعلاتهما لم يُمسّ؛ تغيّرت الألوان والخطوط والغلاف فقط.

## كيف أُضيف…

**محاضرة/فصل لمادة موجودة**
1. انسخ `courses/_template/lecture.html` إلى `courses/<id-المادة>/chapter-3.html` وعدّله
   (أو ضع أي صفحة/PDF جاهز داخل مجلد المادة).
2. في `data/data.js` أضف عنصرًا داخل `chapters` للمادة:
   `{ id:'ch3', n:3, kind:'page', title:'…', label:'…', href:'courses/<id>/chapter-3.html', topics:['…'] }`
   فتظهر تلقائيًا في صفحة المادة والرئيسية والبحث، وتتحول حالة المادة من «قيد الإضافة» إلى «متاحة».

**مصدر/ملف لمادة** — أضف إلى `resources` للمادة: `{ title:'…', kind:'pdf'|'video'|'link', href:'…' }`.

**مادة جديدة** — أضف كائنًا إلى `courses` (انسخ أي مادة موجودة) بـ `chapters: []` لتظهر «قيد الإضافة».

**فصل دراسي/مستوى جديد** — أضف عنصرًا إلى `semesters` (ومرّر `semester:` في موادّه)،
واجعل `current:true` للفصل الحالي فقط.

**شعار الجامعة** — ضع الملف في `assets/img/` ثم اكتب مساره في `logo:` داخل `data/data.js`.
حتى ذلك الحين يظهر رمز بديل محايد.

## ملاحظات على البيانات
- كل المواعيد والقاعات والمدرسين مأخوذة حرفيًا من صورة الجدول الرسمي
  (`Final ITCS TimeTable 2026`، تصدير 2026/10/03). لا شيء مُختلَق.
- الجدول الرسمي يكتب الزمن بلا ص/م (12-2، 10-1). فُسِّر ضمن الدوام النهاري: 12-2 = 12:00→2:00 م.
- الصورة تحمل عبارة «مجموعة الجدول 2 من 2» وعدد ساعات مجدولة 27، بينما المعروض فيها 15 ساعة؛
  أي أن هناك جزءًا آخر من الجدول لم يُزوَّد به المشروع. عند وصوله أضف مواده إلى `data.js`.
